# Steam Hide AI

<p align="center"><img src="https://projects.cdn.aapanasik.com/steam-hide-ai/steam-no-ai.png" width="620" alt="Steam Hide AI: userscript, который скрывает игры с ИИ-контентом в магазине Steam. Предупреждение на странице игры с меткой AI Generated Content Disclosure: причина, текст disclosure разработчика и кнопки «Открыть всё равно», «Назад», «Никогда не скрывать эту игру»"></p>

Userscript для Tampermonkey / Violentmonkey, который скрывает в магазине Steam игры с ИИ-контентом: игры с официальной меткой Steam **AI Generated Content Disclosure** и, по желанию, игры из репортов сообщества.

**[Установить скрипт](https://raw.githubusercontent.com/Suvitruf/steam-hide-ai/master/steam-hide-ai.user.js)** · [English version](README.md)

Этот репозиторий обновляется автоматически. Ошибки и идеи — в [Issues](https://github.com/Suvitruf/steam-hide-ai/issues).

## Что умеет

- **Скрывает игры с меткой в списках магазина**: поиск, страницы тегов и категорий, главная, вишлист и другие списки. Метка есть только на странице самой игры, поэтому скрипт в фоне подгружает страницы (по паре за раз) и кэширует результат на несколько дней.
- **Понимает, для чего использован ИИ.** Текст disclosure от разработчика классифицируется по категориям: арт, текст, голос, музыка, код, видео, генерация в рантайме, другое. По умолчанию скрываются только игры, где ИИ использован для **арта**; можно выбрать любой набор категорий или скрывать все игры с меткой. Классификатор — многоязычная эвристика по ключевым словам, поэтому скрипт всегда показывает, _почему_ игра скрыта, и даёт это переопределить.
- **Три способа скрытия**: убрать карточку, заменить маленькой заглушкой (по умолчанию) или размыть с бейджем. На странице игры — баннер с текстом disclosure и причинами либо предупреждение на весь экран.
- **Ручные правила**: всегда или никогда не скрывать конкретные игры; они сильнее всего остального.
- **Список сообщества** (по умолчанию выключен): вошедшие через Steam пользователи сообщают об играх, где использование ИИ не раскрыто. Список пересобирается раз в час, а сколько репортёров нужно, чтобы скрыть игру, решаете вы (по умолчанию 20).

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Safari, Opera) или [Violentmonkey](https://violentmonkey.github.io/). Greasemonkey **не** поддерживается: в нём нет API для общего хранилища и кросс-доменных запросов, которые нужны скрипту.
2. Откройте [ссылку установки](https://raw.githubusercontent.com/Suvitruf/steam-hide-ai/master/steam-hide-ai.user.js) и подтвердите в менеджере скриптов.
3. Откройте [магазин Steam](https://store.steampowered.com/). Кнопка **ИИ-фильтр** в шапке магазина и пункт _Steam Hide AI: настройки_ в меню менеджера открывают настройки.

Обновления автоматические: менеджер проверяет новую версию по `steam-hide-ai.meta.js`.

## Настройки

| Настройка                               | По умолчанию                           | Примечание                                                                                                                              |
| --------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Игры с официальной меткой Steam об ИИ   | скрывать, если ИИ использован для: арт | Либо скрывать все игры с меткой, либо не скрывать.                                                                                      |
| Как скрывать в списках                  | заглушка                               | Убрать / заглушка / размытие с бейджем. На вишлисте возможны только заглушка и размытие.                                                |
| На странице игры                        | баннер                                 | Баннер с текстом disclosure и причинами, предупреждение на весь экран или ничего.                                                       |
| Проверять игры в списках в фоне         | включено, 2 параллельных запроса       | Выключите, чтобы не было фоновых запросов; проверяться будут только открытые вами игры.                                                 |
| Скрывать игры по репортам сообщества    | выключено                              | Любое использование ИИ или выбранные категории; порог по репортёрам (по умолчанию 20) при фильтре по категориям считается по категории. |
| Всегда / никогда не скрывать эти app ID | пусто                                  | Ручные правила, по одному ID на строку или через запятую.                                                                               |
| Дополнительные ключевые слова           | пусто                                  | Свои слова по категориям для классификатора; `*` в конце — префикс.                                                                     |
| Адрес списка сообщества                 | пусто = этот репозиторий               | Укажите свой список, если ведёте его сами.                                                                                              |
| Язык интерфейса                         | как в Steam                            | Английский или русский.                                                                                                                 |

Настройки можно экспортировать и импортировать в JSON; токен входа в экспорт не попадает.

## Репорты сообщества

Steam не обязывает разработчиков раскрывать использование ИИ, и делают это не все. Список сообщества собирается из репортов реальных аккаунтов Steam:

1. Откройте страницу игры. Под баннером (или над блоком покупки) есть панель **Репорты сообщества**.
2. Нажмите **Войти через Steam**. В новой вкладке откроется стандартный вход Steam; по завершении вкладка закроется сама, а скрипт сохранит токен сессии. Сервер узнаёт только ваш SteamID64, но не пароль и не куки Steam.
3. Нажмите **Сообщить об ИИ-контенте**, отметьте, для чего использован ИИ, при желании добавьте комментарий и отправьте. Репорт потом можно изменить или отозвать. Один репорт на игру с аккаунта; не больше 30 репортов в день.

Раз в час репорты агрегируются в этот репозиторий:

- [`community-list.min.json`](community-list.min.json) — то, что скачивает скрипт: `{ "v": 1, "ts": <unix-секунды>, "apps": { "<appId>": [<репортёров>, { "art": 11, "text": 4 }] } }`.
- [`community-list.json`](community-list.json) — полный список для проверки: по игре число уникальных репортёров, доверенных репортёров, разбивка по категориям и дата добавления.

Игра попадает в список, когда о ней сообщили 5 разных аккаунтов, и выбывает, когда их остаётся меньше 3; ваш собственный порог (по умолчанию 20) применяется поверх этого уже в скрипте. В списке только счётчики, никогда — кто сообщил. Панель на странице игры показывает счётчики из этого списка, поэтому отстаёт от сервера до часа.

## Приватность

- **Страницы магазина.** Чтобы узнать метку игр в списках, скрипт в фоне загружает их страницы (английскую версию), по две за раз, и кэширует результат на 30 дней (метка есть) или 7 дней (метки нет). Это можно выключить в настройках.
- **Список сообщества.** Скачивается из этого репозитория (GitHub) не чаще раза в час.
- **Сервер репортов**. Туда ничего не отправляется, пока вы не войдёте и не отправите репорт. Вход — через Steam OpenID; сервер хранит ваш SteamID64, ваши репорты (игра, категории, комментарий) и хеш IP-адреса для защиты от злоупотреблений. Раз в сутки скрипт сверяет список ваших репортов. Кнопка **Удалить мои данные на сервере** в настройках удаляет всё это.
- В публикуемых данных никогда нет идентификаторов репортёров.
